# Installation Guide

## Requirements

- Python 3.x
- SQLite3 (Built into Python)
- Matplotlib

## Installation

### Clone Repository

```bash
git clone https://github.com/keithnors/transit-tracker.git
cd transit-tracker
```

### Install Required Package

```bash
pip install matplotlib
```

### Run Program

```bash
python main.py
```

## Database

Database file:

```text
database/transit.db
```

will be created automatically when the application runs.
