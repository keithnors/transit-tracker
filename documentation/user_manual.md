# Transit Tracker User Manual

## Overview

Transit Tracker is a Python-based transportation management system that allows users to store, search, update, analyze, and visualize transit records.

## Main Menu

1. Add Record
2. View Records
3. Update Record
4. Delete Record
5. Search Records
6. Sort Records
7. Analytics
8. Charts
9. Export Features
10. Exit

## Adding a Record

1. Select "Add Record".
2. Enter:
   - Vehicle Name
   - Route
   - Departure Time
   - Arrival Time
   - Passenger Count

3. Record will be saved to the database.

## Search Features

Users may search by:
- Route
- Vehicle Name
- Departure Time

## Analytics Features

The system can generate:
- Total Passengers
- Average Passengers
- Most Used Route
- Most Used Vehicle
- Route Statistics

## Charts

The system can create:
- Passenger Bar Chart
- Route Pie Chart
- Vehicle Usage Chart

## Export Features

- Export data to CSV
- Backup database file
